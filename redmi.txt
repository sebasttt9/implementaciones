Proyecto de Microservicios NestJS
Este proyecto está dividido en tres partes principales: el API Gateway (implementacion), el microservicio de hora (microservicio-hora) y varios microservicios adicionales (libros, matemáticas, chat) que se comunican entre sí usando TCP y WebSocket.

¿Cómo funciona?
API Gateway (implementacion):
Es el backend principal. Aquí llegan las peticiones HTTP y GraphQL. El gateway recibe las solicitudes y, si es necesario, las envía a los microservicios por TCP para obtener datos o realizar acciones.

Microservicio de hora (microservicio-hora):
Es un servicio independiente que responde con la hora actual cuando se le pide. El gateway le pregunta la hora usando TCP y muestra el resultado en un endpoint.

Microservicio de libros:
Permite consultar y agregar libros. El gateway se comunica con él por TCP y expone los datos por HTTP y GraphQL.

Microservicio de matemáticas (prueba):
Solo sirve para probar operaciones como suma y multiplicación. No es esencial para el funcionamiento, pero muestra cómo se pueden agregar más servicios.

Microservicio de chat (WebSocket):
Permite que varios usuarios se conecten y chateen en tiempo real. Usa WebSocket y TCP para la comunicación y para verificar que está activo.

Conexiones y comunicación
El gateway se conecta a los microservicios usando TCP (puertos indicados arriba).
El chat usa WebSocket para la comunicación en tiempo real entre clientes.
Los microservicios responden a comandos específicos (por ejemplo, { cmd: 'get_time' } para la hora).
Para probar el chat, abre el archivo index.html en tu navegador y conecta varios usuarios.
Consejos
Si algo no funciona, revisa que todos los microservicios estén corriendo y que los puertos no estén ocupados por otros programas.
El transporte TCP debe estar configurado igual en todos los servicios (variable TRANSPORT=TCP en el .env).
